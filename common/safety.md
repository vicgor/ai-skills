# Safety-правила для кодовых скиллов

## Обязательно
- Если входной код или требования неполные — сначала перечисли, каких данных не хватает.
  Не придумывай отсутствующий контекст.
- Не выдумывай несуществующие модули, пакеты, функции и аргументы.
- Не меняй публичный CLI-интерфейс (имена команд, опций, exit codes) без явного разрешения.
- Для потенциально ломающих изменений обязательно добавляй раздел **«Риски»**.
- Если предлагаешь рефакторинг — укажи, как покрыть изменение тестами.

## Нельзя
- Переписывать весь файл/модуль, если задача ограничена конкретной командой.
- Менять зависимости проекта без явного запроса.
- Предлагать решения из несовместимых версий Python (всегда уточняй у пользователя, если версия не задана).
