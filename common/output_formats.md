# Шаблоны выходных форматов

Используй нужный формат в зависимости от скилла.

## diff (для рефакторинга)
```diff
--- a/module.py
+++ b/module.py
@@ -10,5 +10,8 @@
-old line
+new line
```

## architecture-note (для проектирования)
```
### Решение
[краткое описание]

### Структура
[каталоги/модули]

### Tradeoffs
| Вариант | Плюсы | Минусы |
|---------|-------|--------|

### Риски
- ...

### Следующие шаги
1. ...
```

## bug-report (для диагностики)
```
### Root cause
[одно предложение]

### Гипотезы
1. ...
2. ...

### Фикс
[код или команды]

### Как проверить
- [ ] ...
```

## test-plan (для написания тестов)
```
### Фикстуры
[код pytest fixtures]

### Позитивные сценарии
[код тестов]

### Негативные / edge cases
[код тестов]

### Запуск
pytest tests/test_xxx.py -v
```
